AI-BUG-HUNTER is a Python command-line tool that uses an AI-driven workflow to generate and execute one penetration testing command or script at a time against a target. It can run in an offline fallback mode when the real Google Generative AI API key is not available.

This project is a simple automation helper for security testing. A user tells it a target address and any special guidance. The tool then asks the AI for a safe action, runs that command or script, and captures the output. It repeats this process until the AI indicates it should stop or the configured iteration count is reached. The project also includes a small XSS knowledge base that the AI can reference when forming its responses. The screenshots folder is prepared for terminal output images.
Python 3 is the runtime. The main program is in `main.py`, with support modules in `ai.py`, `command_executer.py`, and `knowledge_base_handler.py`. Install dependencies with `python -m pip install -r requirements.txt`, then run `python main.py --target example.com --guide test --iterations 1 --no-sleep`. If you want real AI behavior, set the `GENAI_API_KEY` environment variable before running. Otherwise the code runs in an offline fallback mode for testing.
